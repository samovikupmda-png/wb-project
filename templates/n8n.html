Входящий вебхук

POST

Используйте этот URL в n8n для отправки команд в WB Tools:

{{ request.host_url }}n8n/webhook
Доступные команды (action):
  • get_tests — список всех тестов
  • get_test_stats + test_id — статистика теста
  • update_stats + variant_id, impressions, clicks
  • complete_test + test_id, winner_variant_id
  • generate_cover + product_id, style, custom_prompt

REST API для n8n HTTP-узлов

Метод Endpoint Описание
GET /api/v1/tests Список всех A/B тестов
GET /api/v1/tests/{id} Детали теста с вариантами
POST /api/v1/variants/{id}/stats Обновить impressions/clicks варианта
GET /api/v1/covers История генераций обложек
POST /api/v1/covers/generate Запустить AI-генерацию обложки
