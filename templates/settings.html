Как создать токены в кабинете WB:
  1. Перейди в Настройки → Доступ к API
  2. Нажми «Создать новый токен»
  3. Выбери нужные разделы (Реклама / Контент / Аналитика)
  4. Скопируй токен и вставь сюда
  5. Можно создать один токен с несколькими разделами сразу
